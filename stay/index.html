세탁·건조마이디어 워시콤보

세탁 15kg · 건조 9kg 일체형이에요. 한 대로 빨고 말리기까지 끝나요.

쓰는 순서

  1. 주머니를 비워요 (동전·라이터·볼펜은 고장 원인이에요)
  2. 빨래를 넣고 문을 딸깍 소리가 나게 닫아요
  3. 세제는 세제함 본세탁 칸, 섬유유연제는 유연제 칸에 넣어요
  4. 코스를 골라요: 세탁+건조 / 세탁만 / 건조만
  5. 시작 버튼을 눌러요

꼭 지켜 주세요

  • 건조까지 할 때는 9kg을 넘기지 마세요. 많으면 나눠서 돌려 주세요
  • 작동 중에는 유리문이 뜨거워요. 문은 끝나고 잠금이 풀린 뒤에 열어 주세요
  • 건조 중간에 멈추면 안쪽 빨래가 뜨거워요. 꼭 멈춰야 하면 바로 꺼내서 펼쳐 주세요
  • 끝나면 바로 꺼내 주세요. 오래 두면 냄새가 나요
  • 울·실크, 고무가 붙은 옷, 방수 옷, 스펀지 패딩은 건조 금지
  • 문을 억지로 열지 마세요

쓰는 순서

  1. 팬을 인덕션 한가운데에 올려요
  2. 재료를 넣고 뚜껑 홈을 회전 날개 기둥에 맞춰 덮어요
  3. 모터 위쪽 회전 스위치를 켜요
  4. 불은 중간 세기로 해 주세요. 예열이 필요 없고 센 불은 팬이 타요
  5. 기름은 팬 손잡이와 뚜껑 손잡이를 같이 잡고 기울여 기름 배출구로 따라내요
  6. 다 쓰면 불과 회전 스위치를 둘 다 꺼요

설거지할 때 (중요)

  1. 고정핀을 시계 반대 방향으로 돌려 모터를 먼저 빼요
  2. 팬·뚜껑·회전 날개만 물로 씻어요
  3. 다시 끼울 때는 고정핀을 시계 방향으로 끝까지 돌려요 (덜 잠기면 날개가 헛돌아요)

  • 쓰는 중이나 막 끝났을 때는 손잡이가 뜨거워요
  • 뚜껑 구멍과 기름 배출구에서 뜨거운 김이 나와요

그 밖의 주방

4요금·비품

수건과 실내 용품은 가져가면 안 돼요수량 체크리스트가 있어서 퇴실할 때마다 확인해요
요금·보증금·환불 규정삼삼엠투 예약 화면이 기준이에요. 보증금은 삼삼엠투가 보관하고 퇴실하면 돌려받아요
전기와 수도는 관리비에 포함돼 있어요너무 많이 쓰면 추가 요금을 요청드릴 수 있어요. 가스는 관리비에 들어 있지 않아요

5문제 해결

도어락이 안 열려요번호를 누른 뒤 # 또는 *를 눌렀는지 확인해 주세요. 그래도 안 열리면 바로 채팅으로 알려 주세요
모니터가 안 나와요마우스 움직이기 → 모니터 전원 확인 → 입력 소스(DP/HDMI) 확인
모니터가 한쪽만 나와요윈도우키 + P → '확장' 선택
컴퓨터가 안 켜져요본체에 불빛이나 팬 소리가 있으면 모니터 문제예요. 반응이 없으면 본체 뒤 전원 스위치와 멀티탭 스위치를 확인해 주세요
세탁기에 E30이 떠요문이 덜 닫힌 거예요. 문을 다시 꼭 닫고 시작해 주세요. 다른 코드는 화면 사진을 채팅으로 보내 주세요
음식물 처리기에 Check가 떠요딱딱한 이물질이나 너무 많이 넣은 음식물을 빼고 시작 버튼을 5초 길게 눌러 주세요. 그래도 같으면 사진과 함께 채팅해 주세요
롤팬 날개가 헛돌아요모터 고정핀을 시계 방향으로 끝까지 돌려 다시 잠가 주세요
에어컨이 안 켜져요리모컨을 본체 쪽으로 겨누고 한 번만 누르기 → 리모컨 건전지 확인
그래도 안 되면삼삼엠투 앱 채팅으로 문의해 주세요

불·연기·가스 냄새·누수가 있으면 바로 대피한 뒤 119에 연락하고 채팅으로 알려 주세요

호스트가 직접 지내 보면서 불편한 점을 하나씩 없앤 공간이에요. 편하게 지내다 가세요. 고맙습니다.
