1꼭 지켜 주세요

도어락번호 누르고 # 또는 *
신발은 현관 앞 신발장실내화로 갈아 신고 들어와요. 실내에서 신발 금지
실내화는 실내용신고 밖으로 나가지 마세요
샤워기는 두 번째 버튼세 번째는 청소용이라 물이 위로 튀어요
샤워커튼 꼭 치기안 치면 물이 밖으로 새요
설거지는 꼭롤팬 모터는 물에 닿으면 고장 나요
분리수거냄새날 것 같은 쓰레기는 중간중간 1층 분리수거장에 버려 주세요
수건·비품은 두고 가기퇴실 때마다 수량을 체크해요
화장실 불 = 비데·온수기·환풍기불 하나로 셋이 같이 켜져요. 씻기 10분 전에 화장실 불을 켜 두시면 따뜻한 물이 나와요. 계속 켜 두면 환풍기 소리가 날 수 있어요
밤 10시부터 새벽까지는 조용히고성방가나 큰 소리는 자제해 주세요
건물 소음 양해 부탁드려요머무시는 동안 다른 호수의 이사나 공사 일정으로 소음이 생길 수 있어요
실내는 금연이에요담배와 전자담배 모두 안 돼요
와이파이실내 QR을 찍거나 공유기 뒷면의 이름·비밀번호로 연결해요
주차는 안 돼요엘리베이터로 4층 409호, 편의점은 걸어서 1분이에요

2기기 사용법

세탁건조기

마이디어 워시콤보 · 세탁 15kg / 건조 9kg
  1. 주머니 비우기 (동전·라이터)
  2. 빨래 넣고 문을 딸깍 닫기
  3. 세제는 본세탁 칸, 섬유유연제는 유연제 칸
  4. 세탁+건조 코스 고르고 시작

건조까지 할 땐 9kg 이하로. 울·실크·고무 붙은 옷은 건조 금지

더 보기
  • 작동 중 유리문이 뜨거워요. 끝나고 잠금이 풀린 뒤 열어요
  • 건조 중간에 멈췄다면 빨래를 바로 꺼내 펼쳐 주세요
  • E30이 뜨면 문이 덜 닫힌 거예요. 다시 닫고 시작해요
  • 끝나면 바로 꺼내 주세요. 오래 두면 냄새가 나요

인덕션

홈플래닛 2구
  1. 왼쪽 전원 버튼을 눌러요
  2. 쓰는 화구 앞 다이얼을 돌려 세기를 맞춰요
  3. 다 쓰면 다이얼을 끝까지 돌려 끄고 전원 버튼

인덕션용 냄비만 돼요. 켠 채로 자리를 비우지 마세요. 끄고 나서도 상판이 한동안 뜨거워요

롤팬 (자동회전 팬)

바이탈플랜트
  1. 팬을 인덕션 한가운데에 올려요
  2. 재료 넣고 뚜껑 홈을 날개 기둥에 맞춰 덮어요
  3. 모터 위 회전 스위치 켜기, 불은 중간
  4. 다 쓰면 불과 회전 스위치 둘 다 끄기

씻을 때: 고정핀을 시계 반대로 돌려 모터부터 빼기. 모터는 물에 담그거나 물을 뿌리면 고장 나요. 마른 행주로만 닦아 주세요

더 보기
  • 기름은 손잡이 두 개를 같이 잡고 기울여 기름 배출구로 따라내요
  • 다시 끼울 땐 고정핀을 시계 방향으로 끝까지 (덜 잠기면 날개가 헛돌아요)
  • 예열이 필요 없어요. 센 불은 팬이 타요
  • 손잡이와 뚜껑 구멍에서 나오는 김이 뜨거워요

음식물 처리기

미닉스 더플렌더 MAX
  1. 앞면 OPEN 버튼을 누르면 윗뚜껑이 천천히 열려요
  2. 통 안 한계선 아래까지만 음식물을 넣어요
  3. 뚜껑을 닫으면 알아서 돌아가요. 따로 누를 버튼은 없어요

넘칠 것 같을 때만 손잡이로 건조통을 꺼내 가루를 일반 쓰레기봉투에 버려요. 아니면 그대로 두고 퇴실하셔도 돼요

넣으면 안 되는 것
  • 조개·게 껍데기, 굵은 생선 뼈, 큰 뼈다귀
  • 파 뿌리, 양파·마늘·옥수수 껍질
  • 호두·밤 껍데기, 복숭아·감 씨, 계란 껍데기
  • 찻잎, 병뚜껑, 나무젓가락, 기름 그 자체
  • 처리 중에 더 넣고 싶으면 OPEN 버튼으로 열고 넣으면 돼요
  • 밥·떡처럼 끈적한 음식은 다른 음식과 섞어서
  • 돌아가는 중에 통 안에 손을 넣지 마세요. 이상한 표시가 뜨면 사진을 찍어 채팅으로 보내 주세요

컴퓨터 2대

듀얼 모니터 · 전동 책상
  1. 비밀번호: 예약 메시지 링크로 열면 보여요
  2. 본인 계정으로 로그인
  3. 퇴실 전에 꼭 로그아웃
더 보기
  • 모니터가 한쪽만 나오면 윈도우키 + P → 확장
  • 책상 높이는 조절 버튼으로. 움직일 때 책상 아래 물건 치우기
  • 의자 하나는 허먼밀러예요

4문제 해결

도어락이 안 열려요번호 뒤 # 또는 *를 눌렀는지 확인 → 안 되면 바로 채팅
모니터가 안 나와요마우스 움직이기 → 모니터 전원 → 윈도우키 + P → 확장
세탁기 E30문을 다시 꼭 닫고 시작. 다른 코드는 사진을 채팅으로
롤팬 날개가 헛돌아요모터 고정핀을 시계 방향으로 끝까지 잠그기
그래도 안 되면삼삼엠투 앱 채팅으로 알려 주세요. 파손·오염도 사진과 함께 바로 알려 주시면 돼요

불·연기·가스 냄새·누수가 있으면 바로 대피 → 119 → 채팅

요금·정산 안내
  • 요금·보증금·환불은 삼삼엠투 예약 화면이 기준이에요. 보증금은 삼삼엠투가 보관하고 퇴실하면 돌려받아요
  • 전기·수도는 관리비에 포함돼요. 너무 많이 쓰면 추가 요금을 요청드릴 수 있어요
  • 가스는 관리비에 들어 있지 않아요
호스트가 직접 지내 보면서 불편한 점을 하나씩 없앤 공간이에요. 편하게 지내다 가세요. 고맙습니다.
