요금·보증금·환불 규정삼삼엠투 예약 화면이 기준이에요. 보증금은 삼삼엠투가 보관하고 퇴실하면 돌려받아요

5문제 해결

모니터가 안 나와요마우스 움직이기 → 모니터 전원 확인 → 입력 소스(DP/HDMI) 확인
모니터가 한쪽만 나와요윈도우키 + P → '확장' 선택. 또는 바탕화면 우클릭 → 디스플레이 설정 → '디스플레이 확장'
컴퓨터가 안 켜져요본체에 불빛이나 팬 소리가 있으면 모니터 문제예요. 반응이 없으면 본체 뒤 전원 스위치와 멀티탭 스위치를 확인해 주세요
세탁기가 멈췄거나 에러가 떠요문이 닫혔는지 확인하고 그래도 같으면 화면을 사진으로 찍어 채팅으로 보내 주세요
음식물 처리기가 멈췄어요문이 닫혔는지, 넣으면 안 되는 음식이 들어갔는지 확인해 주세요. 그래도 멈춰 있으면 사진과 함께 채팅으로 알려 주세요
에어컨이 안 켜져요리모컨을 본체 쪽으로 겨누고 한 번만 누르기 → 리모컨 건전지 확인
도어락이 안 열려요번호를 다시 확인하고 문이 완전히 닫혔는지 봐 주세요. 그래도 안 열리면 바로 채팅으로 알려 주세요
그래도 안 되면삼삼엠투 앱 채팅으로 문의해 주세요

불·연기·가스 냄새·누수가 있으면 바로 대피한 뒤 119에 연락하고 채팅으로 알려 주세요
