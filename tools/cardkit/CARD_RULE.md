# PLAY N 카드뉴스 규칙 v3.1 (사장님 확정 2026-10-15 · 첫 적용: P15 군인 카드뉴스 · 10/17 사진·출처 규칙 추가)
모든 인스타 카드뉴스(캐러셀)는 이 규칙을 먼저 따른다. 원본 시안: 옵시디언 파티룸/플레이앤 사이트/카드뉴스, 레퍼런스: 「범인은?」 제작가이드 + 리서치 노트.

## 1. 표지 (가장 중요)
- 맨 위 작은 머리글: "PLAY N · ○○ 가이드" (시리즈명) + 오른쪽 로고
- 빨간 알약 1개: 타깃 호명 "○○ 예정인 ○○ 필독" (지금 상황이 아니라 곧 결정할 사람을 부른다)
- 제목 3줄, 손님에게 툭 던지는 반말 질문. 핵심 구절 1개만 노란 형광 박스, 끝 "?"만 빨강
  - 예: "자랑스러운 군인이 / 왜 돈 다 내고 / 놀아?" · "4명인데 / 아직도 PC방 / 가?" · "생일인데 / 왜 제값 / 내?"
- 위쪽 글 / 아래쪽 사진 분할. 글을 사진 위에 얹지 않는다 (그리드 썸네일 가독성)
- 사진 아래쪽에 답 한 줄: "인증 1장이면 5만원 할인 + 2시간 더" 처럼 숫자 혜택 + "넘겨보기 →"
- 인사말·감사 문구로 시작 금지 ("○○ 여러분 감사합니다" X)

## 2. 구성 (8장 기본)
표지 질문 → 비교(그냥 vs 혜택 받으면) → 받는 것 3개 → 반전(안 되는 날엔 대신 ○○) → 조건 → 받는 법 3단계 → 📌 저장용 체크리스트 → 보내기 CTA("○○한테 이거 보내")
- 한 편 = 결정 하나. 다른 이벤트 섞지 않기
- 해답을 댓글·DM 뒤에 숨기지 않기. 카드 안에서 다 알려준다
- 실용 정보는 아이콘 칩으로 (🛒 쿠팡 미리 주문 OK · 🧳 짐 미리 맡기기 OK · 🔥 따로 신청 가능)
- 가격은 실제 가격 + 포함 내용 같이 (예: 바베큐 1인 1만원 · 숯·불판 무제한 · 맛있게 드실 것만 챙겨오세요)

## 3. 타이포·디자인
- 제목: 여기어때 잘난체(브랜드 폰트) 92~112px, 줄간격 1.3, 자간 -0.01em, 한 줄 9자 안팎
- 본문: Pretendard 600~800, 36~40px, 줄간격 1.45~1.5, 자간 -0.02em, word-break: keep-all (단어 중간 줄바꿈 금지)
- 강조는 문장당 1개: 노란 박스(#FFC24B, 글자 #141226). 빨강 #FF3355는 "?"·알약·핵심 경고만, 초록 #2BE07A는 완료·링크
- 배경 #0B0A1C, 카드 패널 #17153A + 테두리 #2E2A5E, 둥근 모서리 26~36px
- 1080×1350, 좌우 여백 84px, 핵심 글자는 y 150~1230 (3:4 그리드 크롭)
- 실제 사진만 (AI 이미지 금지), 사진은 둥근 박스로 하단 배치
- **사진은 그 장의 주제와 맞아야 한다 (10/17).** 롤드컵·경기 소재 = 공식 하이라이트 장면·팀 로고, 바베큐 소재 = 바베큐 사진, 장비 소재 = 장비 사진. 화면에 엉뚱한 콘텐츠(음악 앱 등)가 떠 있는 매장 사진은 쓰지 않는다. 직전 3편과 같은 표지 사진 금지
- 팀 로고·선수 얼굴 OK(10/15). 협업·제휴·후원·공식 파트너처럼 읽히는 문구는 금지
- 모든 장 상단 머리글 + 로고, 하단 쪽수 "n / 8"

## 4. 사실·문구 검수
- **출처·Riot 고지문은 카드에 넣지 않는다 (10/17).** 캡션 맨 끝(해시태그 앞) `—` 아래 '출처' 블록에 영상·이미지 / 기록·근거 / 매장 사진 / Riot 고지문을 모은다
- 참여·득표 숫자가 작으면(10 미만) 숫자 대신 순위·문구로 (적은 숫자는 역효과)
- 금액·조건·시간은 실제 운영 규칙만. 후기는 실제 후기만 + 지점·별점 표기
- 할인 안내엔 공통 조건 한 줄: "할인은 playn.kr 예약에만 · 합쳐서 최대 50% · 금·토는 가장 큰 할인 1개만"
- 문체: humanize_rules (AI 티 제거) 적용
- 캡션 첫 줄 = 표지 질문 그대로 + 타깃 키워드, 첫 댓글 = 답하기 쉬운 질문 + 태그 유도 (지킬 수 없는 약속 금지)
- 발행은 사장님 "발행해" 후에만
