PLAY N 릴스 동시 발행 연결

입력한 값은 플레이앤 서버에만 저장되고 이 화면·채팅에 남지 않아요. 이 링크는 사장님만 쓰세요.

① 페이스북 페이지 릴스 확인 중

  1. Graph API 탐색기 열기 → 오른쪽 Meta 앱: NSL Auto Post
  2. 권한 추가에 이 6개가 있는지 확인: instagram_basic instagram_content_publish pages_show_list pages_read_engagement business_management + 새로 pages_manage_posts
  3. Generate Access Token → 「게임파티룸 플레이앤」 페이지와 @playn_no.1 선택 → 허용
  4. 나온 토큰을 아래에 붙여넣기 (앱 시크릿은 저장돼 있어서 비워도 돼요)

② 스레드 확인 중

  1. 앱 이용 사례 → 이용 사례 추가 → Threads API 액세스 → 권한 threads_basic threads_content_publish
  2. 앱 역할 → Threads 테스터에 스레드 계정 추가 → 스레드 앱 설정 → 계정 → 웹사이트 권한 → 초대 수락
  3. Threads API 설정 → 사용자 토큰 생성기 → 토큰 생성 → 아래에 붙여넣기

③ 유튜브 쇼츠 확인 중

  1. 플레이앤 유튜브 채널 만들기 (없으면)
  2. 구글 클라우드 새 프로젝트 → YouTube Data API v3 사용
  3. OAuth 동의 화면: 외부, 앱 이름 Play N → 저장 후 앱 게시(프로덕션)
  4. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션 → 승인된 리디렉션 URI:
    https://bjrgtoyjrggxmdexnwib.supabase.co/functions/v1/playn-publish/ytcb
  5. 나온 클라이언트 ID·보안 비밀번호를 아래에 넣고 → 구글 로그인 → 채널 선택

구글 심사 전에는 올린 쇼츠가 '비공개'로 잠길 수 있어요. 그땐 유튜브 스튜디오에서 공개로 바꾸면 돼요.
