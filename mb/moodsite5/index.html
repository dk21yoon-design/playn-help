이 순서로 여세요

댓글로 신청해주셔서 고마워요. 무드 고르기 → 넓히기 → 웹 화면 → 폰트 → 앱 화면 순서로 열면 레퍼런스 찾는 시간이 줄어요. 주소는 버튼을 누르면 복사돼요.

01Savee · 분위기 고르기

현업 디자이너가 직접 골라 저장한 이미지 모음이에요. 광고 없이 결이 좋은 이미지만 떠서 처음 무드 잡을 때 가장 먼저 열어요. 검색어는 영어로 넣는 게 잘 잡혀요.

https://savee.com/
warm minimal cafe interior

02Cosmos · 같은 결로 넓히기

Savee에서 고른 1장과 비슷한 이미지를 계속 이어서 보여줘요. 무드보드를 금방 채울 수 있어요.

https://www.cosmos.so/

03Godly · 웹 첫 화면과 모션

잘 만든 웹사이트를 고른 갤러리예요. 마우스를 올리면 실제 움직임이 영상으로 재생돼서 스크롤·전환 효과까지 볼 수 있어요.

https://godly.design/

04Maxibestof · 쓴 폰트까지

사이트마다 어떤 폰트를 썼는지 같이 보여주고, 섹션 단위로도 모아봐요. 폰트 조합 고를 때 좋아요. 평일마다 새로 올라와요.

https://maxibestof.one/

05Mobbin · 앱 화면 흐름

실제 앱 화면을 회원가입·결제 같은 흐름별로 모아뒀어요. 버튼 위치와 문구를 비교할 때 봐요. 일부만 무료로 볼 수 있어요.

https://mobbin.com/

06클로드한테 넘기는 문장

고른 레퍼런스 캡처를 붙여넣고 이렇게 시키면 돼요.

첨부한 레퍼런스 3장의 공통점을 색·폰트·여백·레이아웃으로 나눠서 정리해줘. 그 기준으로 우리 카페 소개 페이지 첫 화면을 만들어줘. 이미지는 그대로 베끼지 말고 분위기만 가져와.
