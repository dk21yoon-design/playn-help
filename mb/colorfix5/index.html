정리된 색 5

댓글로 신청해주셔서 고마워요. 영상에 나온 전후 색 코드를 그대로 옮겼어요. 대비 숫자는 WCAG 계산식으로 직접 잰 값이에요.

01글자 대비

회색 글자가 흰 배경에 묻히면 대비를 재보세요. 본문은 4.5 : 1 이상이 기준이에요.

전: 글자 #B4B4B4 / 배경 #FFFFFF → 대비 2.07 : 1
후: 글자 #595959 / 배경 #FFFFFF → 대비 7.0 : 1

02색 개수

한 화면에 색이 일곱 개면 세 개로 줄여요. 배경 60 · 글자 30 · 강조 10 비율로 나누면 정리돼 보여요.

전: #E4007C #00A651 #7B2FF7 #FF6A00 #00C2FF #FFF4B8 #141414 (7색)
후: 배경 #F7F1E6 / 글자 #1E2A44 / 버튼 #E8743B (3색)

03원색

빨강·파랑을 원색 그대로 쓰지 말고 채도를 조금 낮춰요.

전: #FF0000 + #0000FF
후: #C8553D + #2F4A7A

04색 배경 위 회색 글자

노란 배경에 회색 글자는 탁해 보이고 대비도 낮아요. 배경색이 섞인 진한 색으로 바꿔요.

전: 글자 #999999 / 배경 #F6D04D → 대비 1.91 : 1
후: 글자 #5A4500 / 배경 #F6D04D → 대비 6.15 : 1

05강조색

강조색이 제목·가격·링크·버튼에 다 들어가면 버튼이 안 보여요. 한 화면에 한 곳만 써요.

전: 주황 #E8743B 4곳 (제목·가격·링크·버튼)
후: 주황 #E8743B 1곳 (버튼), 나머지는 #141414 · #555555

06클로드한테 시키는 문장

화면 코드를 붙여넣고 아래처럼 시키면 전후 코드를 같이 받아요.

이 화면의 색을 점검해줘. 1) 본문 글자와 배경 대비가 4.5:1 안 되는 곳 2) 쓰인 색이 3개를 넘는지 3) 채도 100% 원색 4) 색 배경 위 회색 글자 5) 강조색이 두 곳 이상인지. 각각 지금 HEX → 바꿀 HEX와 대비 숫자를 표로 보여주고 고친 코드를 줘.

REF참고

레퍼런스 랩에 모은 체크리스트 카드뉴스(릴스 후킹 문구 6가지)의 크림 배경 + 번호 원 + 체크 줄 구성을 따라 만들었어요. 대비 기준은 WCAG 2.2 본문 4.5:1이에요. 예시 카드의 '문방구 카페'는 가상의 가게예요.
