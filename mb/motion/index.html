AI 문방구 · REF INDEX No.03

‘좀 더 역동적으로’ 말고
이름으로 시키세요

댓글로 신청해주셔서 고마워요. 모션은 기법 이름을 알면 클로드든 편집자든 한 번에 알아들어요. 기법마다 그대로 보내는 문장과 코드 값을 적어뒀어요.

PROMPT그대로 보내는 문장

Stretch Text

늘어나고 찌그러지는 글자. 제목에 힘을 줄 때

제목 단어마다 가로로 늘었다 줄게, 단어별로 0.1초씩 늦게

Posterize Time

일부러 뚝뚝 끊기는 움직임. 손으로 그린 듯한 맛

자막 등장 모션을 초당 8프레임으로 끊어줘

Stagger

한 줄씩 시간차로 등장. 목록·자막

목록은 줄마다 0.12초씩 늦게 왼쪽에서 들어오게

Bounce

떨어져서 통통 튀기. 리액션·숫자 강조

통통 자막은 위에서 떨어져 두 번 튀고 멈추게

Mask Reveal

가려졌다가 드러나기. 제목·가격 공개

가격 자막은 왼쪽에서 오른쪽으로 닦아내듯 드러나게

Ease Out

빠르게 와서 살짝 멈추기. 모든 움직임의 기본값

모든 등장 모션은 끝에서 천천히 멈추게(ease out)

CODE바로 붙여 쓰는 값

Stretch Text

transform: scaleX(1.45) scaleY(.83);

Posterize Time

animation-timing-function: steps(8);

Stagger

animation-delay: calc(var(--i) * .12s);

Bounce

anime.js: easing: 'easeOutBounce'

Mask Reveal

clip-path: inset(0 100% 0 0) → inset(0);

Ease Out

transition-timing-function: cubic-bezier(.16, 1, .3, 1);

TIP모션 지시 순서

  1. 기법 이름

    Stagger, Bounce처럼 이름부터

  2. 대상

    제목인지, 자막 한 줄인지, 목록인지

  3. 숫자

    0.12초 간격, 초당 8프레임처럼 숫자로

움직임 줄이기 설정

웹에 넣을 땐 기기에서 움직임 줄이기를 켠 사람에겐 멈춘 화면으로 보여주세요. CSS의 prefers-reduced-motion으로 끌 수 있어요.
