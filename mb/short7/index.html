AI 문방구 · KEY 7

클로드 코드
단축키 7개 한 장 정리

댓글로 신청해주셔서 고마워요. 클로드 코드 공식 문서 기준으로 정리했어요. 예시 문장은 버튼을 누르면 복사돼요.

01Esc

엉뚱하게 가면 바로 멈추기

클로드가 답을 쓰거나 작업하는 중간에 멈춰요. 지금까지 한 작업은 그대로 남아서 바로 방향만 다시 알려주면 돼요.

헤더는 그대로 두고 버튼 색만 바꿔줘

02Esc 두 번

이전 시점으로 되감기

입력창이 비어 있을 때 Esc를 두 번 누르면 되감기 메뉴가 열려요. 대화와 코드를 고른 시점으로 돌려요. /rewind 와 같아요. 입력창에 글자가 있으면 두 번 눌렀을 때 그 글을 지워요.

/rewind

03Shift+Tab

누를 때마다 모드 바꾸기

권한 모드를 돌아가며 바꿔요. 계획 모드(plan mode)에서는 파일을 고치지 않고 읽고 계획만 세워요. 큰 수정 전에 계획 모드로 먼저 보세요. 윈도우에서 안 먹으면 Alt+M.

예약 페이지 고칠 계획만 먼저 세워줘

04! (느낌표)

터미널 명령 바로 실행

맨 앞에 !를 붙이면 클로드를 거치지 않고 명령이 바로 돌아가요. 결과는 대화에 남아서 클로드가 이어서 설명해줘요. 빈 입력창에서 Esc나 Backspace로 빠져나와요.

! npm test
! git status

05@ (골뱅이)

파일 콕 집어주기

@ 뒤에 경로를 치면 자동 완성이 떠요. 파일 위치를 설명할 필요 없이 그 파일부터 읽어요.

@src/cart.js 할인 계산이 이상해. 원인 찾아줘

06Ctrl+V

캡처 이미지 붙여넣기

화면 캡처를 그대로 붙여넣어요. 입력창에 [Image #1] 표시가 생겨요. 윈도우·WSL에서는 Alt+V도 돼요. 맥 iTerm2는 Cmd+V.

[Image #1] 이 화면처럼 버튼 위치랑 색 맞춰줘

07Ctrl+B

오래 걸리는 작업 뒤로 보내기

빌드나 테스트처럼 오래 걸리는 명령을 백그라운드로 보내요. 그동안 다른 일을 시킬 수 있어요. tmux를 쓰면 두 번 눌러요.

빌드 도는 동안 README 정리해줘

TIP알아두면 좋은 것

빈 입력창에서 ? 를 치면 내 환경에서 쓸 수 있는 단축키 목록이 떠요. 터미널마다 조금씩 달라요.
