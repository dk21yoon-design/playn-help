메뉴판 만들 때
깔아둘 도구 5

댓글로 신청해주셔서 고마워요. 클로드 코드 같은 코딩 에이전트에 “이걸로 해줘”라고 하면 설치부터 실행까지 해주는 무료 도구예요. 설치 명령과 시키는 문장은 버튼을 누르면 복사돼요.

01EasyOCR · 종이 메뉴판 글자 뽑기

지금 쓰는 종이 메뉴판 사진에서 메뉴 이름과 가격을 글자로 뽑아요. 한국어도 읽어요. 처음 돌릴 때 모델을 내려받아서 조금 걸려요.

pip install easyocr
easyocr -l ko en -f menu.jpg

02qrcode · 주문 QR 만들기

주문 페이지나 네이버 예약 주소를 넣으면 QR 이미지가 바로 나와요.

pip install "qrcode[pil]"
qr "https://주문페이지주소" > qr.png

03WeasyPrint · 인쇄용 PDF

HTML로 만든 메뉴판을 인쇄용 PDF로 바꿔요. 윈도우는 설치 안내 페이지의 방법을 먼저 따라야 할 수 있어요.

pip install weasyprint
weasyprint menu.html menu.pdf

04Playwright · 인스타용 이미지

같은 메뉴판 HTML을 인스타 피드 크기(1080×1350) 이미지로 찍어요. 파일 주소는 file:/// 로 시작하게 적어요. 처음 한 번은 브라우저 설치가 필요해요.

npx playwright install chromium
npx playwright screenshot --viewport-size "1080,1350" file:///C:/menu/menu.html menu.png

05ImageMagick · 사진 크기 맞추기

메뉴 사진 여러 장을 한 번에 같은 크기로 맞춰요. mogrify는 원본을 덮어쓰니 사본 폴더에서 돌려요.

winget install ImageMagick.ImageMagick
magick mogrify -resize 800x800 *.jpg

06한 번에 맡기는 문장

다섯 개를 이어서 시킬 때 쓰는 문장이에요.

menu.jpg는 지금 종이 메뉴판 사진이야. EasyOCR로 메뉴와 가격을 뽑아서 menu.html 메뉴판을 만들어줘. 주문 주소로 QR을 만들어 오른쪽 아래에 넣고, 인쇄용 menu.pdf와 인스타용 1080x1350 menu.png로 저장해줘. 없는 도구는 먼저 설치해줘.
