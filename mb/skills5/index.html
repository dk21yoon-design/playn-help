01im-not-ai

한국어 글에서 AI 티 지우기

번역투, 뻔한 AI 표현, 쉼표 많은 문장을 찾아 사람이 쓴 문장으로 고쳐요. 캡션·블로그·대본 마지막 손질에 써요.

설치

/plugin marketplace add epoko77-ai/im-not-ai
/plugin install humanize-korean@im-not-ai

캡션 다듬기

/humanize-korean 아래 인스타 캡션에서 AI 티 나는 부분만 고쳐줘. 숫자와 가게 이름은 그대로 둬.

말로 시켜도 돼요

이 글 AI스러움 없애줘

출처 github.com/epoko77-ai/im-not-ai

02frontend-design

AI 티 안 나는 화면 디자인

앤트로픽 공식 스킬이에요. 다 비슷하게 나오던 랜딩 페이지에 업종에 맞는 폰트·색·배치를 먼저 정하고 만들어요.

설치

/plugin marketplace add anthropics/claude-plugins-official
/plugin install frontend-design@claude-plugins-official

새로 만들 때

연남동 동네 빵집 랜딩 페이지 만들어줘. 아침에 굽고 오후 3시면 품절되는 가게라는 느낌이 첫 화면에 보이게. 흔한 보라색 그라데이션은 쓰지 마.

있는 화면 바꿀 때

지금 첫 화면이 템플릿 같아. 업종에 맞게 폰트와 색부터 다시 정하고 고쳐줘.

출처 anthropics/claude-plugins-official

03Impeccable

만든 화면 점검하고 순서대로 고치기

대비·글자 크기·반응형·AI 티를 점검해서 급한 순서로 정리해줘요. 저희 사이트는 17개 걸리던 게 5개로 줄었어요.

설치

npx impeccable install
/impeccable init

올리기 전 점검

/impeccable audit 이 페이지 전체

코드 없이 주소만

npx impeccable detect https://내사이트주소

출처 github.com/pbakaus/impeccable

04Claude in Chrome

브라우저 대신 조작

내 크롬을 열어 검색·클릭·자료 수집을 대신해요. 로그인된 사이트도 그대로 써요. 사진 모아줘 한마디에 144장을 모아왔어요.

설치

크롬 웹스토어에서 'Claude' 확장 설치 후 로그인
claude --chrome

자료 모으기

언스플래시에서 '빈티지 성냥갑' 세로 사진 8장 찾아서 링크랑 같이 표로 정리해줘.

반복 입력

contacts.csv 한 줄씩 읽어서 고객관리 사이트에 연락처로 입력해줘.

출처 code.claude.com/docs/en/chrome
