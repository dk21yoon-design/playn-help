01Swiss Style · 격자 + 산세리프

1950년대 스위스에서 나온 스타일이에요. 보이지 않는 격자에 맞춰 놓고 산세리프 글꼴을 왼쪽 정렬해요. 정보가 많은 카드뉴스에 잘 맞아요.

swiss style poster
Swiss Style poster, strict grid layout, bold sans-serif typography, flush-left text, lots of white space, one accent color

02Memphis · 원색 도형

1980년대 밀라노 디자인 그룹에서 이름이 왔어요. 원색 도형, 지그재그·물결 무늬, 검은 외곽선을 화면 가득 흩뿌려요. 이벤트 공지에 좋아요.

memphis design pattern
Memphis design style graphic, primary color geometric shapes, squiggles and zigzag patterns, black outlines, playful 80s layout

03Brutalism · 일부러 거칠게

꾸밈을 빼고 기본 글꼴, 굵은 테두리, 원색 배경을 그대로 드러내요. 튀어야 하는 포트폴리오·랜딩 페이지에 써요.

brutalist web design
Brutalist web design, default system fonts, thick black borders, raw unpolished layout, flat primary color blocks

04Risograph · 어긋난 인쇄

리소 인쇄기로 찍은 느낌이에요. 2~3가지 별색이 살짝 어긋나게 겹치고 오돌토돌한 입자가 보여요. 포스터·굿즈에 좋아요.

risograph print poster
Risograph print style illustration, two spot colors (fluorescent pink and blue), slight misregistration, grainy texture, paper feel

05Bento Grid · 도시락 칸

도시락 칸처럼 크기가 다른 둥근 상자에 정보를 하나씩 담아요. 큰 칸에 핵심을 두고 작은 칸에 숫자·아이콘을 둬요.

bento grid layout
Bento grid layout, rounded rectangle cards of different sizes, one idea per card, large hero card, clean UI, soft shadows

06클로드한테 쓰는 법

스타일 이름을 붙여 화면이나 카드뉴스를 바로 만들 때 쓰는 문장이에요.

이 내용으로 카드뉴스 표지 만들어줘. 스타일은 Swiss Style: 격자 정렬, 산세리프, 왼쪽 정렬, 포인트 색 하나만.
