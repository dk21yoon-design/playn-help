AI 문방구 · 모션 숫자 5

‘자연스럽게’ 말고
숫자로 적는 모션 5개

댓글로 신청해주셔서 고마워요. 클로드나 챗GPT한테 화면 움직임을 시킬 때 말 대신 넣는 이징·길이 숫자를 정리했어요. 고친 문장은 버튼을 누르면 복사돼요.

01부드럽게 → ease-out 0.3초

빨리 들어와서 천천히 멈춰요

“부드럽게”는 AI마다 다르게 알아들어요. 들어오는 움직임은 ease-out(빠르게 시작해 천천히 멈춤)이 기본이에요. 길이는 0.2~0.4초 사이가 무난해요.

✕ 제목 좀 부드럽게 나오게 해줘

제목은 아래에서 24px 올라오면서 나타나게. ease-out 0.3초.

02빠릿하게 → 0.2초 안으로

버튼 반응은 짧게

눌렀을 때 반응이 늦으면 고장 난 것처럼 느껴져요. 버튼·토글 같은 작은 반응은 0.1~0.2초로 짧게 적어요.

✕ 버튼 누를 때 빠릿하게 반응하게 해줘

버튼 눌림 효과는 0.15초. 누르는 동안 크기 0.96까지 줄였다가 떼면 1로 복귀.

03통통 튀게 → spring

살짝 넘쳤다 제자리

“튀게”라고 하면 과하게 튀거나 아예 안 튀어요. spring(스프링)이라고 쓰고 얼마나 넘칠지 숫자를 같이 적어요.

✕ 좋아요 아이콘 통통 튀게 해줘

좋아요 누르면 아이콘이 spring으로 1.2배까지 커졌다 1배로 돌아오게. 전체 0.4초 안.

04차례로 → stagger 0.05초

줄마다 시작을 조금씩

목록이 한꺼번에 나오면 밋밋해요. 줄마다 시작을 0.05~0.1초씩 늦추는 걸 stagger(스태거)라고 해요.

✕ 목록이 하나씩 차례로 나오게 해줘

목록 줄마다 stagger 0.05초. 각 줄은 fade-up 0.25초, ease-out.

05나갈 땐 → ease-in, 더 짧게

들어올 때보다 짧게

닫히는 창이 열릴 때만큼 오래 걸리면 답답해요. 나가는 움직임은 ease-in(천천히 시작해 빨라짐)으로, 들어올 때보다 짧게 적어요.

✕ 창 닫힐 때도 열릴 때랑 똑같이 해줘

모달 열릴 땐 ease-out 0.3초, 닫힐 땐 ease-in 0.2초. 닫힐 때는 아래로 조금 내려가며 사라지게.
