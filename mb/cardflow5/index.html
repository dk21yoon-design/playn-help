카드뉴스
장마다 역할 5

댓글로 신청해주셔서 고마워요. 카드뉴스가 중간에 넘어가는 건 대부분 장마다 할 일이 정해지지 않아서예요. 장별로 역할과 클로드한테 시키는 문장을 넣었어요.

01표지 · 숫자 + 얻는 것

표지 문장은 두 줄까지만 써요. 숫자 하나와 보고 나서 얻는 것 한 줄이면 충분해요.

[주제] 카드뉴스 표지 문구 5안 써줘. 숫자 하나 + 보고 나서 얻는 것 한 줄. 두 줄 안으로, 느낌표 빼고.

02둘째 장 · 문제 먼저

둘째 장에서 바로 해결책을 꺼내면 왜 봐야 하는지 몰라요. 읽는 사람이 겪는 장면 하나를 먼저 보여줘요.

둘째 장은 해결책 말고 [대상]이 겪는 문제 한 장면으로 써줘. "이런 적 있죠?" 느낌으로 두 문장 안.

03본문 · 한 장에 하나

본문 한 장에는 팁 하나만 넣어요. 제목·부제·본문 크기를 세 단으로 나누면 훑어봐도 읽혀요.

본문을 한 장에 팁 하나씩 나눠줘. 장마다 제목 / 부제 / 본문 3단으로, 본문은 3줄 안. 몇 장이 되는지 먼저 알려줘.

04진행 표시 · 번호와 막대

몇 장 남았는지 보이면 끝까지 넘겨요. 큰 번호(01. 02.)나 아래 진행 막대 중 하나를 써요.

장마다 왼쪽 위에 큰 번호 01. 02. 를 넣고 아래에 진행 막대(현재 장 / 전체 장)를 그려줘.

05마지막 장 · 요약 + 키워드 하나

마지막 장은 한 줄 요약과 댓글 키워드 하나로 끝내요. 키워드가 두 개면 둘 다 안 남겨요.

마지막 장은 전체를 한 줄로 요약하고 댓글 키워드는 하나만 넣어줘. 예: 댓글에 "구성표" 남기면 보내드려요.

06한 번에 시키는 문장

주제만 바꿔서 쓰면 돼요.

[주제]로 인스타 카드뉴스 7장 구성해줘. 1장 표지(숫자+얻는 것 2줄) · 2장 문제 한 장면 · 3~6장 팁 하나씩(제목/부제/본문 3단) · 7장 한 줄 요약+댓글 키워드 하나. 장마다 큰 번호와 진행 막대 위치도 적어줘.
