영상 만드는 도구 3

댓글로 신청해주셔서 고마워요. 클로드 코드 같은 코딩 에이전트에 붙여 쓰는 영상 도구 3개예요. 설치 명령과 처음 시킬 문장은 버튼을 누르면 복사돼요.

01Remotion

리액트 코드로 만드는 영상

그래프, 숫자 카운트, 데이터처럼 정확하게 움직여야 하는 영상에 좋아요. 공식 문서에 클로드 코드용 스킬 설치 방법이 같이 나와요. 회사 규모에 따라 유료 라이선스가 필요할 수 있으니 remotion.dev 라이선스 안내를 먼저 보세요.

npx create-video@latest
Remotion 스킬로 매출 그래프가 0에서 1200까지 올라가는 15초 세로 영상 만들어줘

02HyperFrames

HTML이 그대로 영상으로

웹페이지 만들듯 HTML·CSS로 짜면 MP4로 렌더링돼요. 자막과 그래픽이 많은 쇼츠에 잘 맞아요. 헤이젠이 만든 오픈소스(Apache 2.0)예요. Node.js 22 이상이 필요해요.

npx skills add heygen-com/hyperframes
하이퍼프레임즈로 30초 세로 쇼츠 만들어줘. 자막은 화면 아래, 장면 5개

03OpenMontage

대본부터 편집까지 한 줄로

대본, 소스 찾기, 편집, 렌더까지 이어서 돌리는 제작 라인이에요. 무료 스톡 영상을 모아 잘라 붙이는 방식도 지원해요. AGPLv3 라이선스라 결과물 말고 코드를 고쳐 배포할 땐 조건을 확인하세요. FFmpeg가 필요해요.

git clone https://github.com/calesthio/OpenMontage.git cd OpenMontage make setup
비 오는 도시를 주제로 60초 영상 만들어줘. 실제 영상 소스만, 내레이션 없이 음악만

04틀 재사용

한 번 만든 틀은 주제만 바꿔서

세 도구 모두 결과가 코드로 남아요. 마음에 든 영상의 틀을 두고 문장만 바꾸면 다음 편이 금방 나와요.

지난번 영상 틀(색·자막 위치·길이)은 그대로 두고 주제만 바꿔서 하나 더 만들어줘
