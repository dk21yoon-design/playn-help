사이트 5곳

댓글로 신청해주셔서 고마워요. 영상에 나온 사이트 주소와 상업용으로 써도 되는지 확인하는 순서를 정리했어요. 주소는 버튼을 누르면 복사돼요.

SITE무료 영문 폰트 사이트 5곳

01 Fontshare

인도 폰트 회사 ITF가 운영해요. 사이트 안내에 모든 폰트가 개인·상업용 무료라고 적혀 있어요(ITF 무료 라이선스 또는 OFL). Satoshi, Clash Display, General Sans가 인기예요.

https://www.fontshare.com

02 Velvetyne

파리의 폰트 디자이너 모임이에요. 무료 오픈소스 폰트만 올리고, 실험적인 모양이 많아서 포스터·앨범 커버 제목에 잘 어울려요.

https://velvetyne.fr

03 Collletttivo

이탈리아 디자이너 모임의 오픈소스 폰트예요. 수는 적지만 하나하나 개성이 강해요. OFL이라 상업용으로 써도 돼요.

https://www.collletttivo.it

04 Open Foundry

오픈소스 폰트를 골라서 화면 가득 크게 보여줘요. 두세 개를 띄워놓고 비교할 때 편해요.

https://open-foundry.com

05 Uncut

요즘 디자이너들이 쓰는 폰트를 모아둔 목록이에요. 무료·유료가 섞여 있어서 받기 전에 각 폰트 라이선스를 꼭 확인하세요.

https://uncut.wtf

CHECK상업용 확인하는 법

  1. 폰트 페이지에서 License 찾기 OFL(SIL Open Font License)이면 상업용·로고·영상 모두 돼요. 폰트 파일만 따로 파는 건 안 돼요.
  2. “Personal use only”면 쓰지 않기 개인용만 허락된 폰트는 가게 홍보물·유튜브에 쓰면 안 돼요.
  3. 받은 날짜와 주소 남기기 라이선스는 바뀔 수 있어요. 받은 날 페이지 캡처를 같이 저장해두세요.

PROMPT클로드한테 폰트 고르게 하기

영문 제목 폰트를 골라줘. 분위기는 [분위기], 쓰는 곳은 [포스터·썸네일·로고]. Fontshare, Velvetyne, Collletttivo, Open Foundry에 있는 폰트 중에서 3개만 추천하고, 폰트마다 라이선스 이름과 페이지 주소를 같이 적어줘. 확인 못 한 건 확인 못 했다고 말해줘.
