06클로드한테 시키는 문장

지금 쓰는 화면이나 카드뉴스 코드를 붙여넣고 이렇게 시키면 제목 폰트만 바꿔서 비교해줘요.

이 화면 영어 제목 폰트를 Instrument Serif, Bricolage Grotesque, Space Grotesk, Fraunces, League Gothic 다섯 개로 각각 바꾼 버전을 만들어줘. 구글 폰트 링크로 불러오고 한글은 Pretendard로 두고, 다섯 개를 한 화면에 나란히 보여줘서 비교할 수 있게 해줘.

CHECK쓰기 전에 확인

구글 폰트 페이지에서 Get font → Download all 누르면 받아져요. 라이선스는 각 페이지 아래 License 칸에서 OFL인지 한 번 더 보세요. 폰트 파일 자체를 되파는 건 안 돼요.
