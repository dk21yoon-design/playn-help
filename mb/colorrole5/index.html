색이 촌스러우면
말을 바꿔요 5

댓글로 신청해주셔서 고마워요. 색이 이상하게 나오는 건 감각 문제가 아니라 시키는 말이 넓어서예요. 전후 문장을 그대로 복사해서 쓰세요.

01역할별로 정하기

"예쁜 색"이라고 하면 매번 다른 색이 나와요. 배경·제목·강조·버튼처럼 색이 맡을 자리를 먼저 나눠요.

전: 예쁜 색으로 꾸며줘 후: 배경, 제목, 강조, 버튼 색을 따로 정해줘. 역할마다 하나씩, HEX 코드로.

02HEX 코드로 적기

"파란 계열"은 하늘색부터 남색까지 다 들어가요. 정한 색이 있으면 코드로 적어요.

전: 파란 계열로 해줘 후: 배경 #1E2A5A, 글자 #F5F3EE, 강조 #FFC94D 로 맞춰줘.

03비율 60 : 30 : 10

색 개수보다 넓이가 중요해요. 주색 60, 보조색 30, 강조색 10으로 나누면 정돈돼 보여요.

전: 색 여러 개 써서 화려하게 후: 배경 60, 카드 30, 강조 10으로 나눠줘. 강조색은 버튼과 숫자에만.

04대비 4.5 : 1 이상

본문 글자는 배경과 대비 4.5:1 이상이 웹 접근성(WCAG AA) 기준이에요. "잘 보이게" 대신 숫자로 말해요.

전: 글자 잘 보이게 해줘 후: 글자와 배경 대비 4.5:1 이상으로 맞춰줘. 안 되면 글자색을 바꾸고 바꾼 대비 값도 알려줘.

05예시 화면에 입혀보기

색 다섯 개를 나란히 놓으면 다 괜찮아 보여요. 제목·카드·버튼이 있는 화면에 입혀야 고를 수 있어요.

전: 어울리는 색 조합 추천해줘 후: 제목, 카드, 버튼이 있는 예시 화면을 만들어서 색 조합 3안을 각각 입혀 보여줘.

06팔레트 사이트

직접 고르고 싶으면 이 세 곳을 써요. Happy Hues는 색마다 쓰는 자리를, Realtime Colors는 내 색을 예시 사이트에 입혀서 보여줘요. 대비는 WebAIM에서 확인해요.

https://www.happyhues.co/ https://www.realtimecolors.com/ https://coolors.co/ https://webaim.org/resources/contrastchecker/
