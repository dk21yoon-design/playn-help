촌스러운 영상
범인은 색이에요

댓글로 신청해주셔서 고마워요. 장르별로 바로 쓰는 자막 색 조합이에요. HEX 코드는 버튼을 누르면 복사돼요.

01정보성

흰색 + 노랑 하나

배경이 뭐든 잘 읽혀요. 강조할 단어 하나만 노랑으로 칠하고 나머지는 흰색. 검은 테두리나 반투명 검은 박스를 깔면 더 또렷해요.

#FFFFFF #FFD60A #111111

02브이로그

크림 + 코랄

순백 대신 크림색을 쓰면 화면이 따뜻해져요. 포인트는 코랄, 그림자·박스는 짙은 갈색.

#FFF4E0 #FF7A59 #3B2A20

03감성

라벤더 + 민트

파스텔 박스에 글자는 진한 남색으로 써야 흐려지지 않아요. 흰 글자는 파스텔 위에서 잘 안 읽혀요.

#CDB4FF #B9F3E4 #2B2D42

04게임

네온 그린 + 핑크

검정 바탕에 형광 두 색. 장면이 빨리 바뀌어도 눈에 들어와요. 두 색을 한 문장에 같이 쓰진 마세요.

#39FF14 #FF2BD6 #0A0A0A

05먹방·리뷰

주황 + 빨강

음식 사진과 잘 붙는 따뜻한 색. 글자는 흰색, 강조만 주황, 가격·할인은 빨강.

#FF8C1A #E63946 #FFFFFF

06색 고르는 도구

Coolors · Realtime Colors (둘 다 무료)

Coolors(coolors.co) Trending에서 좋아요 많은 팔레트를 보고 HEX를 복사해요. Realtime Colors(realtimecolors.com)에 글자·배경·포인트 색을 넣으면 예시 화면에 바로 입혀서 대비를 확인할 수 있어요.

https://coolors.co/palettes/trending
https://www.realtimecolors.com

TIP한 가지 규칙

한 영상에 포인트 색은 하나만. 자막 색은 흰색(또는 크림) 하나로 고정하고 강조 단어만 포인트 색을 쓰면 촌스러움이 확 줄어요.
