손으로 하던 영상 작업
맡기는 도구 5

댓글로 신청해주셔서 고마워요. 클로드 코드 같은 코딩 에이전트에 “이걸로 해줘”라고 하면 설치부터 실행까지 해주는 무료 도구예요. 설치 명령과 시키는 문장은 버튼을 누르면 복사돼요.

01whisper · 자막 파일 자동

영상이나 음성을 넣으면 받아쓰기해서 srt 자막 파일을 만들어요. 오픈AI가 공개한 오픈소스(MIT)예요. FFmpeg가 필요해요.

pip install -U openai-whisper
whisper로 영상.mp4 한국어 자막 srt 만들어줘. whisper 영상.mp4 --language Korean --output_format srt

02auto-editor · 무음 구간 컷

소리 크기를 보고 말 없는 구간을 알아서 잘라내요. 토크 영상 1차 컷에 좋아요.

pip install auto-editor
auto-editor로 영상.mp4에서 말 없는 구간 잘라줘. auto-editor 영상.mp4

03ffmpeg · 자막 입히기

만든 srt 자막을 영상 위에 바로 구워요. 다른 도구들도 대부분 이걸 같이 써요. 윈도우는 winget, 맥은 brew로 깔아요.

winget install Gyan.FFmpeg
ffmpeg로 자막.srt를 영상에 입혀줘. ffmpeg -i 영상.mp4 -vf subtitles=자막.srt 완성.mp4

04demucs · 목소리·배경음 분리

녹음에 음악이나 소음이 섞였을 때 목소리만 따로 뽑아요. 처음 돌릴 때 모델을 내려받아서 조금 걸려요.

python -m pip install -U demucs
demucs로 녹음.mp3에서 목소리만 뽑아줘. demucs --two-stems=vocals 녹음.mp3

05rembg · 사진 배경 지우기

썸네일에 쓸 인물·제품 사진 배경을 한 줄로 지워요. 결과는 배경이 투명한 png예요.

pip install "rembg[cpu,cli]"
rembg로 사진.png 배경 지워줘. rembg i 사진.png 누끼.png

06한 번에 맡기는 문장

다섯 개를 이어서 시킬 때 쓰는 문장이에요.

영상.mp4로 쇼츠 만들 준비해줘. auto-editor로 무음 잘라내고, whisper로 한국어 자막 srt 만들고, ffmpeg로 자막 입혀서 완성.mp4로 저장해줘. 없는 도구는 먼저 설치해줘.
