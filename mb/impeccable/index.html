AI가 만든 티를 거르는
Impeccable 프롬프트 모음

댓글로 신청해주셔서 고마워요. 설치부터 바로 붙여 쓰는 문장까지 이 페이지에 다 있어요. 버튼을 누르면 복사되고, 아래 버튼으로 한 파일에 받아갈 수도 있어요.

STEP설치 3단계

  1. 프로젝트 폴더에서 설치
    npx impeccable install
  2. 클로드 코드 다시 열기

    설치 중에 자동 점검(hook)을 켤지 물어보면 켜두세요. 수정할 때마다 알아서 점검해줘요.

  3. 처음 한 번 초기 설정
    /impeccable init

    내 서비스가 누구를 위한 건지 몇 가지 묻고 PRODUCT.md로 정리해요. 이후 명령은 전부 이 파일을 읽고 움직여요.

PROMPT상황별로 붙여 쓰기

지금 페이지가 어디서 본 것 같을 때

점수 매긴 리뷰와 먼저 고칠 순서를 받아요.

/impeccable critique 첫 화면(히어로 섹션)

올리기 전에 마지막 점검

접근성·성능·반응형을 급한 순서(P0~P3)로 정리해줘요.

/impeccable audit 이 페이지 전체

너무 밋밋할 때

/impeccable bolder 가격표 카드

너무 시끄럽고 정신없을 때

/impeccable quieter 메인 페이지

폰트·글자 크기가 엉망일 때

/impeccable typeset 본문과 제목

마무리 손질

/impeccable polish 예약 섹션

처음부터 새로 만들 때

요청에 업종·대상·분위기를 같이 적으면 결과가 좋아져요.

/impeccable 연남동 동네 빵집 랜딩 페이지 만들어줘. 아침에 굽고 오후 3시면 품절되는 가게라는 느낌이 첫 화면에 보이게. 다 만들면 npx impeccable detect로 점검해서 걸린 건 고쳐줘.

TIP잘 쓰는 법

대상은 좁게

"홈페이지 전체"보다 "가격표 카드", "첫 화면"처럼 한 부분을 집어줄수록 결과가 좋아요.

코드 없이 점검만

터미널에서 주소만 넣어도 돼요. 크롬 확장 프로그램으로 아무 사이트나 열어 점검할 수도 있어요.

npx impeccable detect https://내사이트주소

브랜드 폰트가 걸릴 때

일부러 쓰는 폰트라면 예외로 등록하면 돼요.

npx impeccable ignores add-value overused-font Inter --reason "Brand font"

STEERquieter
