개인정보처리방침

PLAY N 게임파티룸(홍대루프탑·연남루프탑·연트럴파크, 이하 "플레이앤")은 이용자의 개인정보를 소중히 다루며 관련 법령을 지킵니다. 시행일: 2026년 10월 8일

1. 수집 항목과 목적

  • 예약·이용: 이름, 휴대폰 번호, 이용 일시 — 예약 확인, 입실 안내, 청소·운영 일정 관리
  • N CREW 가입: 이름, 휴대폰 번호, 자주 가는 지점 — 공실 특가·이벤트 알림 (동의한 경우에만)
  • 홈페이지 방문 통계: 본 페이지 주소, 들어온 경로(링크의 from 값·이전 사이트 주소), 기기 종류(모바일/PC), 브라우저에 저장되는 무작위 방문 번호 — 홈페이지 개선과 홍보 효과 측정. 이름·전화번호·IP 주소는 수집하지 않으며 쿠키를 쓰지 않습니다. 브라우저 저장소를 지우면 방문 번호도 삭제됩니다.

2. 보관 기간

예약 정보는 이용 후 관계 법령이 정한 기간까지, N CREW 정보는 탈퇴(수신 거부) 시까지 보관한 뒤 지체 없이 파기합니다.

3. 제3자 제공·위탁

법령에 따른 경우를 제외하고 개인정보를 제3자에게 제공하지 않습니다. 문자 발송과 데이터 보관을 위해 국내외 클라우드·문자 서비스를 이용할 수 있습니다.

4. 유튜브 API 서비스 이용

플레이앤은 자체 유튜브 채널에 홍보 영상(쇼츠)을 올리기 위해 YouTube API 서비스를 사용합니다. 이 기능은 플레이앤 운영자 계정에만 쓰이며, 일반 이용자의 구글·유튜브 계정 정보는 수집하지 않습니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침
  • 연결 해제: Google 보안 설정 → 서드파티 액세스에서 언제든 권한을 철회할 수 있습니다.

5. 이용자의 권리

이용자는 언제든 자신의 정보 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 문자 수신 거부는 문자에 안내된 방법으로 바로 할 수 있습니다.
